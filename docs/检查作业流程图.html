HXD3D 型电力机车 · 整备检查作业流程图

按"检查部位"组织 · 教学演示用 · 实际作业以现场规程为准
主流程步骤 含关键/高风险项 合格判据 辅助步骤

0作业准备（前置）

车外 · 通用

检查人员到岗、防护用品穿戴齐全；确认机车已停电、防溜措施到位；与列检、整备场协调一致。

  • 确认作业分工、准备记录本或手持终端
  • 检查工具、检测仪器校验有效
  • 确认防护信号、禁动牌、接地线状态
通用项

1车顶高压设备

车顶 · 受电弓/主断/避雷器

接触网停电、验电、接地后方可登顶。

  • 受电弓滑板 / 弓头 / 框架
  • 车顶绝缘子 / 支持瓷瓶
  • 主断路器 / 避雷器 / 隔离开关
  • 车顶母线紧固、无遗留物
5 项全为关键项雷雨禁止

2司机室

车内 · 操纵区

操纵、监控、制动、通信、消防与安全装备齐全完好。

  • 司控器 / 制动控制器 / 压力表
  • LKJ 监控与机车信号
  • CIR 电台 / 列尾装置
  • 仪表 / 开关 / 指示灯
  • 灭火器 / 紧急阀 / 门窗刮雨器
7 项含 5 项关键

3机械间 / 设备舱

车内 · 变流/通风/制动柜

断电后检查变流柜、牵引通风、空压机、制动柜与控制电源。

  • 主变流器 / 牵引电机
  • 通风机 / 冷却 / 滤尘
  • 空压机 / 干燥器 / 排污
  • 制动柜 / 管路 / 控制电源
  • 防火与整洁 / 报警装置
6 项含 3 项关键

4走行部

车下 · 转向架 / 轮对

轮对、轴箱、悬挂、牵引电机、基础制动与撒砂排障。

  • 踏面 / 轮缘 / 锤击
  • 轴箱 / 轴温
  • 一系 / 二系悬挂 / 减振器
  • 牵引电机 / 齿轮箱
  • 基础制动 / 闸片
  • 撒砂 / 排障器
6 项含 5 项关键严禁踩踏闸片

5制动系统

车下 / 车内 · 风源与管路

总风、安全阀、管路漏泄与制动缓解，停放制动功能可靠。

  • 总风缸 / 安全阀 / 排水
  • 管路漏泄
  • 制动缓解作用
  • 停放制动
  • 紧急制动 / 撒砂联锁
5 项全为关键项
▲ 步骤 5 须在 步骤 4 走行部检查完成且确认车下无人、车下作业解除后进行

6车钩缓冲装置

端部 · 车钩 / 缓冲器 / 风管

钩体、钩舌、钩锁销、缓冲器、风管与电气连接。

  • 钩体 / 钩舌（裂纹锤击）
  • 钩锁销 / 提钩装置
  • 缓冲器 / 从板
  • 车钩高度（测量）
  • 风管 / 塞门 / 电气连接
5 项含 3 项关键

7端部与信号

端部 · 前照灯 / 标志灯 / 附属

灯具、刮雨器、扶手脚踏、车号、自动过分相。

  • 前照灯 / 标志灯
  • 鸣笛 / 刮雨器
  • 端部结构与扶手
  • 自动过分相感应器
4 项含 1 项关键

8制动机性能试验

司机室 · 全列制动

漏泄试验、常用制动与缓解、紧急制动、备用制动并签认。

  • 充风 / 漏泄
  • 常用制动与缓解
  • 紧急制动（联锁切断牵引、撒砂）
  • 备用制动 / 记录签认
4 项含 3 项关键

9结果汇总与交车

车外 · 司机室

系统生成检查报告，核对异常处置，填写签认；与调度、列检办理交接。

  • 汇总合格项 / 异常项 / 未检项
  • 导出或打印检查记录
  • 异常处置已闭环或明确监护要求
  • 工具回收、清扫现场、撤除防护信号
